# Phase 3 (frontend, sub-project 5) — Lịch năm học, PPCT, TKB giáo viên, Sổ báo giảng — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** UI (`apps/web`, JavaScript) cho 4 mảng của Phase 3: lịch năm học (ngày nghỉ + 4 thẻ thống kê, ADMIN thêm/sửa/xóa), PPCT theo vị trí (nhập tay + import Excel có xem trước sửa được), thời khóa biểu giáo viên (lưới tuần kiểu Google Calendar + GVBM khai báo tiết), sổ báo giảng (theo tuần mọi lớp / theo môn-lớp, tích "Đã thực hiện", kéo-thả hoặc "Chuyển ngày" để chỉnh tay).

**Architecture:** 4 slice RTK Query mới (`school-calendar-api`, `ppct-api`, `timetable-api`, `lesson-logs-api`) theo khuôn `*-api.js` hiện có, kèm 1 test tích hợp kiểm invalidation chéo. Thành phần dùng chung ở `components/schedule/` (WeekNav, TimetableGrid, LessonWeekBoard, SlotPanel…), helper thuần ở `lib/schedule.js` + `lib/ppct.js`. Trang top-level (`/lich-nam-hoc`, `/thoi-khoa-bieu`, `/so-bao-giang`, `/phan-phoi-chuong-trinh`) cho dữ liệu theo giáo viên/toàn trường; trang theo lớp (`/lop-hoc/[classId]/{ppct,thoi-khoa-bieu,so-bao-giang}`) cho dữ liệu theo Position (GVCN/ADMIN xem được). UI chỉ ẩn/hiện control theo quyền (`canEditPosition`, `RoleGate`) — quyền thật ở guard backend.

**Tech Stack:** Next.js 14 App Router + JavaScript (`.jsx`/`.js`), Tailwind + primitives `components/ui`, Redux Toolkit/RTK Query, `@so-chu-nhiem/shared` (chỉ hằng số), Jest + React Testing Library (jsdom). KHÔNG thêm dependency mới (không thư viện kéo-thả, không thư viện ngày).

**Spec:** [docs/superpowers/specs/2026-10-11-phase3-design.md](../specs/2026-10-11-phase3-design.md) (mục 4.4 bảng API + 3.1/3.2) và plan backend [2026-10-11-phase3-backend.md](./2026-10-11-phase3-backend.md) (shape response + bảng lỗi — đang được agent khác thực thi song song, KHÔNG sửa). ## Global Constraints

- **Lệnh shell**: mọi lệnh `pnpm`/`node` chạy sau `source ~/.nvm/nvm.sh && nvm use 20 &&` (plan viết rút gọn). **V-WEB** = `pnpm --filter web run lint && pnpm --filter web run test`. Chạy 1 file: `pnpm --filter web run test -- <mẫu tên>`.
- **`apps/web` import `@so-chu-nhiem/shared` qua `packages/shared/dist`**: sau khi backend Task 1 merge (hoặc rebase lên nhánh có nó), chạy `pnpm --filter @so-chu-nhiem/shared run build` rồi mới chạy test web — import thiếu export KHÔNG báo lỗi mà ra `undefined` âm thầm (xem Task 1, bài test cổng).
- **Tailwind chỉ quét `./app/**` và `./components/**`** (xem `tailwind.config.js`): bản đồ class động (màu theo môn…) phải nằm trong 2 thư mục này, không đặt ở `lib/`. **Không dùng modifier độ mờ trên token màu dạng `var(--x)`** (`bg-brand/10`, `bg-danger/10`…): đã kiểm chứng Tailwind 3.4.19 KHÔNG sinh CSS nào cho chúng ở dự án này → dùng token `*-soft` (Task 2).
- **Ngày**: giá trị ngày nội bộ là chuỗi `yyyy-mm-dd`. Backend trả ngày dạng ISO `2026-01-08T00:00:00.000Z` (00:00 UTC) ở bản ghi và `yyyy-mm-dd` ở `weekStart`/`weekEnd` → luôn chuẩn hóa bằng `toDateOnly`. Hiển thị `dd/mm/yyyy` bằng `formatDate` (đã dùng `timeZone: 'UTC'`); cộng/trừ ngày bằng `shiftDateOnly` (UTC). "Hôm nay" = `todayDateOnly()` (`lib/utils.js`) — CẤM `new Date().toISOString().slice(0, 10)` (lỗi Critical của sub-project 3: lùi 1 ngày lúc 00:00–07:00 giờ VN) và CẤM `new Date('yyyy-mm-dd')` rồi dùng getter giờ địa phương.
- **Thứ/tuần**: `dayOfWeek` 2–7 = Thứ 2…Thứ 7 (Chủ nhật = 1, không bao giờ có tiết). Tuần = Thứ Hai→Chủ Nhật; Chủ Nhật thuộc tuần của Thứ Hai ngay trước nó (khớp `resolveWeekStart` backend). FE luôn gửi `weekStart` tường minh (đã chuẩn hóa về Thứ Hai).
- **RTK Query**: mỗi domain 1 file `lib/store/*-api.js` dùng `apiSlice.injectEndpoints`; mọi mutation gọi `.unwrap()` (bài học Important của sub-project 2); lỗi hiển thị bằng `apiErrorMessage(err, fallback)` (Task 1). Không dùng `useEffect` để đồng bộ state từ mảng RTK Query (vòng render — xem chú thích ở `diem-danh/page.jsx`): dùng `useMemo` + reset theo giá trị nguyên thuỷ.
- **Phân quyền hiển thị** (control không có quyền KHÔNG được render, test bằng `queryByRole`; backend vẫn là nơi chặn thật): GVBM giữ vị trí SUBJECT sửa PPCT/TKB/sổ báo giảng của đúng vị trí đó; GVCN (giữ HOMEROOM) chỉ XEM mọi môn trong lớp; ADMIN sửa mọi vị trí SUBJECT và ngày nghỉ; GVBM môn khác KHÔNG được thấy môn đó trong bộ chọn (backend 403); STUDENT không thấy mục nào. `/timetable/me` và `/lesson-logs/week` chỉ TEACHER (ADMIN 403) → trang tương ứng bọc `RoleGate roles={['TEACHER']}`.
- **Không logic nghiệp vụ ở FE**: FE không tự xếp tiết, không tự kiểm tra ngày chuyển có hợp lệ, không tự tính thống kê, không tự kiểm tra ngày kết thúc ≥ ngày bắt đầu — các lỗi quan hệ do backend trả (400/409) và FE hiển thị nguyên văn. Ngoại lệ DUY NHẤT: tiền kiểm ràng buộc từng ô của dòng PPCT (số/độ dài) vì import là "tất cả hoặc không gì" và cần chỉ ra dòng nào sai.
